# 보안프로그램 개발 2일차 제출용 요약

## 1. 개발 방향

우리 팀은 피싱 문자 탐지 프로그램을 웹 UI 방식으로 개발하기로 했다.

사용자가 의심 문자와 첨부파일 정보를 입력하면 프로그램이 문자 안의 위험 신호와 URL을 분석하고, 첨부파일은 존재 여부와 확장자를 점수로 반영하여 위험도를 출력한다. Ollama로 실행되는 개인 로컬 AI는 문자와 URL 중심으로 추가 종합 분석을 수행한다.

## 2. 탐지기준

주요 탐지기준은 다음과 같다.

- APK 설치 유도: `.apk`, `/install`, `/download`
- 정부기관 사칭: 정부지원금, 환급금, 보조금, 국민검진
- 긴급성 표현: 긴급, 오늘 마감, 즉시 신청, 자동 취소
- 금전 요구: 송금, 입금, 계좌, 수수료, 항공료
- 고수익 유혹: 재택알바, 투자, 비트코인, 리딩방
- 생활 밀착형 사칭: 부고, 청첩장, 결혼식, 검진 결과
- 보이스피싱 연계: 문의전화, 고객센터, 수사관, 안전계좌
- 로맨스 스캠: 사랑, 미래 약속, 항공료 요청

## 3. 프로그램 로직

```text
문자/파일 입력
  ↓
문자 전처리 및 첨부파일 여부 확인
  ↓
위험 키워드 및 URL 검사
  ↓
탐지된 항목 점수 합산
  ↓
AI 종합 분석 요청
  ↓
위험도 등급 분류
  ↓
탐지 이유와 대응 방법 출력
```

## 4. 위험도 기준

| 점수 | 위험도 |
|---:|---|
| 0~19점 | 안전 |
| 20~49점 | 주의 |
| 50~79점 | 위험 |
| 80점 이상 | 매우 위험 |

## 5. 웹 UI 구성

웹 화면은 다음 요소로 구성한다.

- 문자 입력창
- 파일 선택창
- 분석하기 버튼
- 초기화 버튼
- 위험도 표시
- 점수 표시
- AI 종합 판단
- URL 분석 결과
- 첨부파일 점수 결과
- 탐지 이유 목록
- 권장 행동 안내

## 6. 구체적 기능

1. 사용자가 문자와 첨부 파일을 입력한다.
2. 서버가 URL, APK, 사칭 키워드, 긴급 표현, 금전 요구 표현을 검사한다.
3. 첨부파일은 내용 분석 없이 존재 여부와 확장자를 점수에 반영한다.
4. 탐지된 항목마다 점수를 더한다.
5. Ollama 로컬 AI 모델에 종합 분석을 요청한다.
6. 총점과 AI 판단을 바탕으로 위험도를 정한다.
7. 위험한 이유와 대응 방법을 화면에 출력한다.
