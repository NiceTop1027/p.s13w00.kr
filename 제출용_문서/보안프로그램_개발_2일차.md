# 보안프로그램 개발 2일차

## 1. 개발 주제

피싱 문자를 분석하여 위험도를 판단하고 사용자에게 경고하는 보안 프로그램을 개발한다.

이 프로그램은 문자 메시지 안에 포함된 단어, 링크, 긴급 표현, 금전 요구 표현 등을 기준으로 점수를 계산한다. 첨부파일은 AI가 직접 분석하지 않고, 첨부파일 존재 여부와 확장자만 점수에 반영한다. 계산된 점수에 따라 `안전`, `주의`, `위험`, `매우 위험` 단계로 분류하고 사용자에게 대응 방법을 안내한다.

## 2. 탐지기준 정하기

### 2-1. 핵심 탐지 항목

| 탐지 항목 | 예시 | 위험도 |
|---|---|---|
| APK 설치 유도 | `.apk`, `/install`, `/download` | 매우 높음 |
| 정부기관 사칭 | 정부지원금, 환급금, 국민검진, 보조금 | 높음 |
| 긴급성 유도 | 긴급, 오늘 마감, 즉시 신청, 자동 취소 | 중간 |
| 금전 요구 | 송금, 입금, 계좌, 수수료, 항공료 | 높음 |
| 고수익 유혹 | 재택알바, 하루 15만원, 3일 만에 2배 | 높음 |
| 감정적 접근 | 자기야, 사랑해, 보고 싶어, 미래 약속 | 중간 |
| 행사/생활 사칭 | 부고, 청첩장, 검진통지서 | 중간 |
| 의심 URL | `http://`, 짧은 주소, 알 수 없는 도메인 | 높음 |
| 외부 메신저 이동 | 카카오톡, 텔레그램, 오픈채팅 | 중간 |
| 첨부파일 점수 | 첨부파일 포함, `.apk`, `.exe`, `.zip` | 중간~매우 높음 |

| 조건 | 점수 |
|---|---:|

| 고수익/알바/투자 유도 표현 포함 | +25 |
| 부고/청첩장/검진 등 생활 밀착형 사칭 표현 포함 | +20 |
| 텔레그램/카카오톡 등 외부 채팅 이동 유도 | +15 |
| 사랑/연애/미래 약속 등 로맨스 스캠 표현 포함 | +15 |
| 첨부파일 포함 | +10 |
| 위험 확장자 첨부파일 | +20~+60 |

### 2-3. 위험도 등급

| 총점 | 등급 | 프로그램 반응 |
|---:|---|---|
| 0~19점 | 안전 | 별도 경고 없음 |
| 20~49점 | 주의 | 의심 문구 표시 |
| 50~79점 | 위험 | 링크 클릭 주의 경고 |
| 80점 이상 | 매우 위험 | 차단 권장 및 강한 경고 |

## 3. 프로그램 로직 작성

### 3-1. 기본 동작 순서

1. 사용자가 문자 내용을 입력한다.
2. 프로그램이 문자 내용을 소문자 변환 및 공백 정리한다.
3. 문자 안에 URL이 있는지 검사한다.
4. `.apk`, `/install`, `/download` 같은 악성 앱 설치 유도 패턴을 검사한다.
5. 정부지원금, 환급금, 검진통지서 등 기관 사칭 키워드를 검사한다.
6. 긴급, 마감, 즉시 신청 등 사용자를 재촉하는 표현을 검사한다.
7. 송금, 입금, 계좌, 투자, 고수익 등 금전 관련 표현을 검사한다.
8. 부고, 청첩장, 검진 등 생활 밀착형 사칭 표현을 검사한다.
9. 첨부파일이 있으면 존재 여부와 확장자에 따라 점수를 더한다.
10. 각 조건에 맞는 점수를 더한다.
11. 총점에 따라 위험도 등급을 결정한다.
12. 사용자에게 위험도, 탐지된 이유, 권장 행동을 보여준다.

### 3-2. 순서도

```text
문자 입력
  ↓
문자 전처리
  ↓
URL 포함 여부 검사
  ↓
APK/설치 링크 검사
  ↓
사칭 키워드 검사
  ↓
긴급성 표현 검사
  ↓
금전 요구 표현 검사
  ↓
생활형 사칭 표현 검사
  ↓
첨부파일 점수 반영
  ↓
위험 점수 계산
  ↓
위험도 등급 분류
  ↓
경고 메시지 출력
```

### 3-3. 의사코드

```text

    score += 15

    score += 10

    score += 20

if message에 "긴급", "마감", "즉시", "제한시간", "자동취소"가 있으면:
    score += 15
    reasons에 "긴급성을 이용한 클릭 유도" 추가

if message에 "송금", "입금", "계좌", "수수료", "항공료"가 있으면:
    score += 30
    reasons에 "금전 요구 가능성" 추가

if message에 "재택알바", "고수익", "투자", "비트코인", "2배"가 있으면:
    score += 25
    reasons에 "고수익 또는 투자 사기 가능성" 추가

if message에 "부고", "청첩장", "결혼식", "검진 결과"가 있으면:
    score += 20
    reasons에 "생활 밀착형 피싱 가능성" 추가

if 첨부파일이 있으면:
    score += 10
    reasons에 "첨부파일 포함" 추가

if 첨부파일 확장자가 ".apk", ".exe", ".bat", ".js", ".zip"이면:
    score += 20~60
```

## 4. 구체적 기능구현 서술

### 4-1. 문자 입력 기능

사용자가 받은 문자 내용을 프로그램에 입력한다. 실제 앱으로 구현할 경우 문자 메시지를 직접 가져오는 기능을 추가할 수 있지만, 초기 개발 단계에서는 텍스트 입력창에 붙여넣는 방식으로 구현한다.

### 4-2. 키워드 탐지 기능

피싱 문자에서 자주 등장하는 단어를 목록으로 저장해두고, 입력된 문자에 해당 단어가 포함되어 있는지 검사한다.

예시 키워드:

- 지원금, 환급금, 보조금, 국민검진
- 긴급, 마감, 즉시 신청, 제한시간
- 송금, 입금, 계좌, 수수료
- 재택알바, 고수익, 투자, 비트코인
- 부고, 청첩장, 결혼식, 검진 결과

### 4-3. URL 탐지 기능

문자 안에 `http://`, `https://`, `www.` 같은 링크 형식이 있는지 확인한다. 링크가 있으면 기본 위험 점수를 추가하고, `http://`처럼 보안 연결이 아닌 경우 추가 점수를 준다.

### 4-4. APK 설치 유도 탐지 기능

문자 안에 `.apk`, `/install`, `/download`가 포함되어 있으면 악성 앱 설치 유도 가능성이 높다고 판단한다. 특히 `.apk`는 정상적인 문자 안내에서 거의 사용되지 않기 때문에 높은 점수를 부여한다.

### 4-5. 위험도 점수 계산 기능

각 탐지 조건에 맞는 점수를 더해 최종 점수를 만든다. 단순히 한 단어만 보고 판단하지 않고 여러 위험 신호가 동시에 나타나는지 확인한다.

예시:

```text
[정부지원금 신청 안내]
오늘 마감입니다. 아래 앱 설치 후 본인 인증을 진행해 주세요.
http://gov-support-app.kr/install.apk
```

탐지 결과:

- APK 링크 포함: +50
- 정부지원금 키워드: +20
- 오늘 마감: +15
- http 링크: +15
- URL 포함: +10

총점: 110점  
결과: 매우 위험

### 4-6. 결과 출력 기능

프로그램은 분석 결과를 사용자에게 다음과 같이 보여준다.

```text
위험도: 매우 위험
점수: 110점
탐지 이유:
- 악성 앱 설치 유도 가능성
- 정부기관 사칭 가능성
- 긴급성을 이용한 클릭 유도
- 보안 연결이 아닌 URL 사용

권장 행동:
- 링크를 클릭하지 마세요.
- 앱을 설치하지 마세요.
- 문자 발신자를 공식 기관에 직접 확인하세요.
- 이미 설치했다면 즉시 삭제하고 비밀번호를 변경하세요.
```

## 6. 탐지기준 재정의

처음에는 단순히 `.apk` 링크나 정부지원금 키워드만 탐지하려고 했지만, 피싱 문자의 종류가 다양하므로 탐지기준을 넓힌다.

재정의한 탐지기준:

1. 악성 앱 설치 유도형
   - `.apk`, `/install`, `/download`
   - 알 수 없는 앱 설치 유도

2. 정부기관 사칭형
   - 정부지원금, 환급금, 보조금, 국민검진
   - 공식 기관처럼 보이게 만든 가짜 링크

3. 금전 요구형
   - 송금, 입금, 계좌, 수수료
   - 항공료, 치료비, 급한 돈 요구

4. 고수익 유혹형
   - 재택알바, 투자, 비트코인, 2배 수익
   - 텔레그램 또는 오픈채팅 이동 유도

5. 생활 밀착형 사칭
   - 부고, 청첩장, 검진 결과
   - 사용자의 호기심이나 불안감을 이용한 링크 클릭 유도

6. 긴급성 유도형
   - 오늘 마감, 즉시 신청, 긴급, 자동 취소
   - 사용자가 충분히 확인하지 못하게 만드는 표현

## 9. 최종 정리

이 프로그램은 피싱 문자에 포함된 위험 신호를 탐지하고 점수화하여 사용자가 링크 클릭이나 악성 앱 설치를 피할 수 있도록 돕는 보안 프로그램이다.

2일차 개발에서는 탐지기준을 정하고, 점수 기반 로직을 작성했으며, 웹 UI 형태의 화면 구성과 추가 기능 계획까지 정리하였다. 다음 단계에서는 실제 코드로 문자 입력, 키워드 탐지, 위험도 계산, 결과 출력 기능을 구현할 예정이다.
